# Contributing

1. Open an issue that names the official source of any rate change.
2. Change `data/logisvert.json`, copy it to `docs/logisvert.json`, add or update a test.
3. Run `python -m unittest discover -s tests` and `python benchmarks/run.py`.
4. Sign each commit with `git commit -s` ([Developer Certificate of Origin](https://developercertificate.org/)).

Be respectful; disagreements are settled with sources.
